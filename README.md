# RomaAdjei-Cybersecurity-Portfolio
"*Offensive security & network analysis coursework, CTF write-ups, and applied labs.*"
I'm a cybersecurity student/practitioner focused on offensive security and network defense. This repository collects hands-on labs, coursework, and CTF write-ups demonstrating practical experience across web application attacks, network traffic analysis, exploitation frameworks, and digital forensics.
